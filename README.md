Big Data – Hadoop, PySpark, NoSQL & Real‑Time Streaming Analytics
Scalable Multi‑Domain Streaming Pipeline built with HDFS, PySpark, NoSQL and Live API Feeds for Sports and Weather Data.
The project demonstrates end‑to‑end big data processing using Hadoop HDFS, PySpark, NoSQL databases, and Spark Streaming for real‑time analytics.

Project Overview
This project focuses on building a distributed data pipeline using:

Hadoop Distributed File System (HDFS)

PySpark for large‑scale data processing

MongoDB for NoSQL storage

Spark Streaming for real‑time ingestion and analysis

A real‑world dataset (GlobalWeather) is collected from a public source and processed across all components.
